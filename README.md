# Pokémon Explorer — Projeto Front-End

Projeto acadêmico feito com HTML, CSS e JavaScript puro, consumindo a PokéAPI.

## Precisa de chave?
Não. A PokéAPI é gratuita e não exige autenticação para os endpoints públicos da versão 2.

Documentação: https://pokeapi.co/docs/v2

## Como executar
1. Extraia a pasta do projeto.
2. Abra `Pokemon_Explorer` no VS Code.
3. Abra `index.html` com a extensão Live Server (recomendado).
4. O site carregará os primeiros 24 Pokémon automaticamente.

É necessária conexão com a internet para consultar a API e carregar as imagens.

## Funcionalidades
- Listagem paginada de Pokémon.
- Busca por nome ou número.
- Filtro por tipo.
- Cards criados dinamicamente com `document.createElement`.
- Consumo da API com `fetch` e `async/await`.
- Inserção dos cards com `appendChild`.
- Layout responsivo para celular e computador.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: visual e responsividade.
- `script.js`: requisições à API e criação dos cards.
- `teoria.pdf`: parte teórica (até 3 páginas).
- `roteiro_pitch.txt`: roteiro para o vídeo pitch.
